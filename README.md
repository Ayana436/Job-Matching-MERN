# AI Resume Screening and Recruitment Platform

## Objective

The objective of this project is to automate candidate screening and job matching using Artificial Intelligence techniques. The system allows recruiters to publish job openings and candidates to upload resumes for AI-powered matching and application tracking.

---

## Technology Stack

### Frontend
- React.js
- Axios
- CSS3

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- JWT Authentication
- Role-Based Access Control

### AI / NLP
- PDFJS
- TF-IDF
- Cosine Similarity
- Keyword Matching

### Additional Services
- Nodemailer
- Multer

---

## Features

### Candidate Module

- User Registration/Login
- Resume Upload (PDF)
- Resume History Management
- Resume Deletion
- AI Resume Analysis
- Job Search
- Job Matching Score
- Quick Apply
- Application Tracking

### Recruiter Module

- Recruiter Registration/Login
- Create Job Openings
- Edit Jobs
- Delete Jobs
- View Applicants
- Accept/Reject Candidates
- Email Notifications

### AI Features

- PDF Resume Parsing
- Skill Extraction
- TF-IDF Analysis
- Cosine Similarity Matching
- Match Score Generation
- Missing Skill Detection
